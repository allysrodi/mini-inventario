# Mini Inventario

Mini Inventario es una web de inventario: cada persona inicia sesión, registra
sus productos y ve cuáles están por debajo de su cantidad mínima.

## Entorno
- Node.js 22 (22.20 o superior) para la web.
- Python 3.12 para el servidor MCP.
- En Windows, los comandos se ejecutan en PowerShell 7.

## Reglas
- Cada cambio va en una rama nueva y se integra con pull request. Nunca trabajes directo en `main`.
- Nunca subas llaves, tokens, contraseñas ni archivos `.env`.
- Pide aprobación antes de borrar datos o desplegar.
- Explica cada comando antes de ejecutarlo.
- La bitácora de cada día va en `entregas/dia-XX/README.md`.
