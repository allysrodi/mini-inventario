# Mini Inventario

Web de inventario para registrar productos y ver cuáles están por debajo de su cantidad mínima.

## Requisitos

- Node.js 22 (22.20 o superior)
- Python 3.12

## Cómo empezar

1. Clona el proyecto:

   ```bash
   gh repo clone allysrodi/mini-inventario
   cd mini-inventario
   ```

2. Comprueba las versiones:

   ```bash
   node --version
   npm --version
   python3 --version
   ```

   Node debe mostrar `v22.x` (22.20 o superior) y Python `3.12.x`.
